# 手机镜像缓存

## 定位

服务器的 DSH session event log 是唯一权威源。Android 使用 Room 保存一份可删除、可重建的镜像，让冷启动、弱网浏览和草稿编辑保持即时；缓存绝不能单独推进 Agent 状态。

## 缓存内容

- 已配对服务器的非秘密标识、最后同步时间和协议版本。
- session summary、标题投影、运行状态与最后访问顺序。
- 最近会话的已提交 history events、最高连续 `seq` 和渲染所需 tool view。
- 当前会话、抽屉/主题偏好及每会话未发送草稿。

设备 token 单独由 Android Keystore 保护，不进入 Room。模型凭据、API key、完整附件字节和待审批答案不写入缓存。缓存的事件与 tool result 可能含敏感代码和路径，因此 Room 中的 payload 使用 Keystore AES-GCM 加密后再落盘。

## 启动与同步

1. 原生层立即返回缓存快照，UI 标记为“正在同步”。
2. App 校验 Gateway health 与认证，拉取 `session.list`。
3. 按 session id 合并摘要；服务器缺失且已完成一次权威列表读取的缓存项才删除。
4. 当前会话拉取 history tail，以 `seq` 去重并覆盖未确认的流式片段。
5. 建立 mux/host 流；已提交事件分批写回缓存，短暂 chunk 只用于内存渲染。

## 离线规则

- 可查看已缓存会话、搜索已缓存文本和编辑草稿。
- 发送、取消、模型切换、设置修改、工具审批和问题回答全部要求在线。
- 不建立“稍后自动执行”的 prompt 队列；恢复网络后必须由用户再次确认发送。
- 缓存清除只影响离线与首屏速度，不删除服务器会话。

## 容量

首版默认缓存最近 30 个会话、每个会话最近 300 个已提交事件；LRU 淘汰只影响本地镜像。用户可在设置中清理缓存，后续版本再提供容量档位。
