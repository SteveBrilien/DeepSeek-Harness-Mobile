# DSH Mobile 设计规范 v1

## 风格定位

保留 DSH 的鱼形标识、Fluent 风格矢量图标、主题 token 和信息密度；导航、触控、键盘与系统反馈遵循移动端行为。目标不是 Material 组件换皮，也不是另造一套渐变、发光、玻璃拟态品牌。

## 色彩

所有产品色必须引用集中 token，不在组件中添加“看起来接近”的紫色或彩色渐变。基线直接沿用 DSH 已有色号：

- 黑：`#0f1115` 页面背景、`#151517` 一级表面、`#1b1b1c` 二级表面、`#232324` 选中/悬停。
- 白：`#f9fafb` 主要文字。
- 灰：`#adb2b8` 次要文字、`#81858c` 说明文字、`#ffffff0f`/`#ffffff1f` 边框。
- 蓝：`#4176e6` 主操作、`#5686fe` 强调/图标、`#26314833` 蓝色弱背景。
- 红、绿、琥珀只用于错误、成功/在线和警告状态，不用于装饰。

配对页只允许纯背景、DSH 标识、标题、两项输入、一个主按钮和安全说明；禁止展示性光晕、轨道、插画和多色渐变。

## 尺寸

- 基础栅格：4dp；主要布局步长：8dp。
- 页面水平边距：16dp；紧凑卡片内边距：12dp。
- 最小触控区域：48×48dp；图标视觉尺寸：20–24dp。
- 顶栏：52dp + `safe-area-inset-top`。
- 输入卡：最小 56dp，文本区最大 `40dvh`。
- 抽屉宽度：`min(86vw, 336dp)`。
- 圆角：控件 8–10dp、卡片 12dp、输入器 16dp；状态胶囊可使用 999dp。

## 字体

- 页面标题：20/28，600。
- 分组标题：16/24，600。
- 正文与输入：16/24，400。
- 控件文字：14/20，500。
- 辅助与状态：12/18，400。
- 必须支持系统字体缩放到 130%，不截断主要动作。

## 页面结构

- 手机：一次只显示一个主页面。
- 会话与工作区：左侧抽屉。
- 设置：列表页进入全屏详情页，系统返回键逐级返回。
- 模型、权限、简单选择：底部 Sheet。
- 轨迹：从对话页进入全屏时间线；工具卡可展开。
- 审批：接管输入器区域，拒绝与“仅本次允许”并列显示。

## 状态语言

- `连接中`、`已连接`、`离线`、`正在重连` 必须显式区分。
- `正在思考`、`工具运行中`、`等待审批`、`正在停止` 不得共用一个无限旋转状态。
- 网络错误保留用户输入并提供重试；禁止用模拟答案掩盖错误。
- 不支持的服务能力隐藏；暂未实现但已规划的功能不得伪装为可点击项。

## 动效与无障碍

- 页面与 Sheet：160–240ms；按压反馈不超过 80ms。
- 尊重 `prefers-reduced-motion`。
- 所有图标按钮必须有可读名称；颜色不是唯一状态编码。
- 正文、代码、工具输出可选择复制；横向代码滚动不得拖动整页。
